# 本地快速裁图工具

## 打开方式

推荐双击：

```text
C:\Users\Microsoft\Documents\Ozon\local-crop-tool\start-local-crop-tool.bat
```

也可以直接打开：

```text
C:\Users\Microsoft\Documents\Ozon\local-crop-tool\index.html
```

## 当前支持

- 固定尺寸：800×800、800×1200、1200×1200、750×1200。
- 可添加自定义尺寸。
- 批量导入图片，按选中的多个尺寸一次生成预览。
- 自动识别图片主体，让模特尽量居中。
- 全身图：头部默认保留至少 30px，下方默认保留至少 20px。
- 上半身图：头部默认保留至少 30px，下方不强制留白。
- 下半身图：上方不强制留白，下方默认保留至少 20px。
- 左上角固定位置添加 Logo，可调整左边距、上边距、Logo 宽度和透明度。
- 输出 JPG、PNG、WebP。
- 单批最多加入 50 张原图、生成 120 张输出图。
- 预览使用较低分辨率，点击下载时才生成高清成品，减少大量图片时的内存占用。

## 使用流程

1. 打开本地裁图工具。
2. 拖入或选择需要裁切的商品图片。
3. 勾选需要输出的尺寸。
4. 选择图片类型：自动判断、全身、上半身、下半身。
5. 选择 Logo 文件，并确认左上角位置。
6. 点击“生成预览”。
7. 检查预览后，点击单张下载或“下载全部”。

## 自动裁切说明

工具会从图片边缘估算背景颜色，再计算与背景不同的主体范围。适合白底、浅灰底、纯色背景、常规电商模特图。

遇到以下情况时，建议人工微调：

- 背景复杂或有大面积道具。
- 服装颜色和背景非常接近。
- 图片里有多人。
- 原图本身已经把头部或脚部切掉。

可调整项：

- 主体框容错：数值越小，越容易把细节识别进主体；数值越大，越容易忽略接近背景的区域。
- 横向微调：正数向右移动裁切区域，负数向左移动。
- 纵向微调：正数向下移动裁切区域，负数向上移动。

## 本地化说明

图片和 Logo 都只在当前浏览器内处理，不会上传到外网。工具本身不依赖外部服务。
