# V1.37 类目主动选品实施计划

**目标：** 独立类目入口，与店铺扫描共用解析、运输风险、查重、商品池与核价规则。通过用户提供的 Ozon 真实类目 URL 创建单窗口队列。

**架构：** 独立本地任务 `ozonCategoryBatchV1`，只访问显式类目页面；每个任务分别记录来源、观察 SKU、商品、页码和状态。共用已有商品池核心与云端人工交接 CSV，无需外部 API。仅按已采集人民币售价筛选，非网页价格条件。目标计数为本机新合格候选，云端最终入池由自身历史去重后决定。工作台只查看已同步类目批次并人工入池，扩展启动本地任务。

**约束：** 最多20个类目，目标1–500件；与店铺扫描互斥，保留各自任务数据。仅在精确同源类目主列表、SKU/链接一致、明确符合要求、可交接时接受商品；无法核对/验证码/登录/访问限制时暂停或部分完成，不绕过。仅发现明确同类目下一页才翻页；等待和页数有界。保留原核价、运输及历史门槛，不开启1688/PDD、不购买、不联系商家。
