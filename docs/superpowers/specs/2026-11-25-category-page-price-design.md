# V1.50 类目网页价格预筛选

目标：减少无效商品加载，不改变原人民币价格、ERP 标签、运输、去重和人工找品规则。

方案比较：按人民币自动兑换卢布需要汇率来源、精度和时效，可能误筛；用户确认采用单独填写 Ozon 原生卢布区间，保留人民币复核。无卢布区间时不改变原有行为。网页实测中国专区选择 500–2500 ₽ 后生成 `currency_price=500.000%3B2500.000`，普通汽车类目使用相同条件并显示对应价格筛选。仅支持两端均填写（整数卢布 0–10,000,000）；不猜测单边参数、不自动汇率换算、不更改站点账号/语言/币种。

批次固定保存已确认的区间；每个类目从带区间的第一页开始。翻页必须保持同一类目、同一价格区间和合法页码，拒绝未知参数及变更区间；只容许已观察到的站点自动附加的有限标记并在比较时移除。若站点未显示一致的卢布控件，等待有限次数后暂停并提示人工检查，禁止静默放宽筛选。实际候选仍通过原有本机 CNY/ERP/运输/去重逻辑。旧批次没有设置则继续原有流程。

两版同源；测试包括设置、真假价格控件、跨类目、翻页保持、篡改/丢失价格范围、原人民币门槛、历史诊断及管理页。真实站点筛选界面已核实；实际扩展端到端及筛选效率需单独验收。
