## V1.58 / 0.6.76 及以前已上线版本摘要

- V1.58 / 0.6.76（已上线站点版本 `87`，`d1537b8`）：支持多电脑共用同一工作台账号协作时按「扫描设备」或「扫描批次（电脑 + 时间）」筛选商品池（`deviceId` / `batchId`），独立版 `searchVersion` `3 → 4`。回滚备份 `_备份_20261127_v158_device_batch_filter_before`。
- V1.57 / 0.6.75（已上线站点版本 `86`，`b46d5c6`）：新增 `savedRecent` / `savedOldest` 保存时间排序并剔除无用 `skuAsc` / `skuDesc`；详情页推送后经 `GET /api/ozon?sku=`、`ozon-pricing-pushed` 唤醒与 2s 轻量轮询实现快速核价秒级回显。
- V1.56 / 0.6.74（已上线站点版本 `84`，`b18194b`）：修复工作台商品池底部悬浮栏「取消选择」按钮“白底白字”并统一双版悬浮栏按钮配色。
- V1.55 / 0.6.73（已上线站点版本 `83`，`4f43d4b`）：精简快速核价右侧栏（合并「货源链接 / 备注」，移除冗余文本框）并更新侧栏「任务工作台」「灵感图库」图标。
- V1.54 / 0.6.72（随 V1.55 上线）：工作台新增 `OzonShell` 左侧栏与 `Ctrl+K` 快捷跳转；双版商品池改为紧凑列排布、缩略图 168×168 悬停预览与底部悬浮批量栏。
- V1.53 / 0.6.71（已上线站点版本 `81`，`44feaa5`）：商品池新增缩略图懒加载、月销量列与来源筛选（类目/店铺），CSV 补充图片链接。
- V1.52 / V1.51 / 0.6.70（已上线站点版本 `80`，`f198089`）：商品池迁入 D1（`0019`、`0020` 迁移通过，账号 `yehui` 262 件一致，`ready=1`），每页 50 件，独立版迁入 IndexedDB 事务分块分页。
- 本机治理：Ozon 为共享核心真源；`tools/sync-workbench-core.mjs` 校验工作台 9 处共享文件同步锁；默认移除 Chrome 不支持可选申请的 `debugger` 权限；工作台历史 ESLint 72 错误 / 75 警告留待另行治理。

## 0.6.40–0.6.69 历史记录与早期边界（原样保留）

- 0.6.69 / V1.50：新类目任务可设置独立 Ozon 页面卢布价格区间，两端均填或均空；已确认普通类目、中国专区真实页面均支持范围参数。翻页保留区间，未确认控件或条件变化则暂停；原 CNY、ERP、运输和查重标准不变。
- 0.6.68：类目采集诊断按 SKU 统计筛选及查重原因，记录真实增长时间和浏览器状态，一键导出本机诊断。
- 0.6.67：暂停或停止的当前类目批次支持指定类目继续、跳过和删除（移出扫描队列）。
- 0.6.66：类目识别按唯一 Ozon 商品链接和对应毛子 ERP 卡片绑定，适配同一行标签、隐藏 SKU 和跟卖最低价、三档小数佣金。
- 0.6.65：新批次独立窗口，不抢前台；新增发现商品、ERP 就绪、标签命中三个诊断指标。
- 0.6.64：后台普通等待持续约 90 秒且没有新增已检查 SKU，保留本页、候选和待复查记录，先扫未开始类目，再回查一次。
- 0.6.63：类目弹窗默认中国专区，普通类目置于高级选项；独立任务监控恢复失联读取器不导航或刷新，冻结/节流显示等待。
- 0.6.62 类目选择：三级并列联动弹窗、完整已选路径和单项移除、中文/俄文/编号/路径搜索、组合与“选末级”。
- 0.6.61 类目批次管理：本机删除已结束当前/历史批次与清理零候选批次；工作台使用账号和批次范围内软删除标记。
- 0.6.60 修复：排除具有明确推荐标题的独立推荐岛，读取唯一明确的分页容器（含虚拟行）。
- 0.6.59 类目树：基于 2026-10 公开目录快照（普通 2,434 节点，中国专区 1,191 可选节点），普通与中国专区 ID 命名空间独立。
- 0.6.58 类目验证误判修复：修复普通 SKU 和价格数字触发误暂停问题。
- 0.6.57 类目反复暂停修复：同一明确主类目容器内多个网格可合并；页末有未加载字段自动回查最多两轮。
- 0.6.45 / 0.6.44 / 0.6.41：增加核价发送目标与手动/自动批次同步；批量店铺扫描页保留人工找品表 CSV、原始汇总 CSV、Markdown 和备用 Agent JSON；**1688 自动搜款主线暂停**（恢复前须有用户明确指示，1688 单件/三件/20 件门槛继续保留为未来恢复路线验收要求）。
