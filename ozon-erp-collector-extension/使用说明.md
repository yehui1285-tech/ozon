# OZON ERP 详情页采集助手使用说明

当前版本：`0.5.9`

## 0.5.9 核价页视觉更新入口

- “打开核价页”和商品页发送流程改用 `v=20260711` 地址，减少浏览器继续命中旧版核价页缓存的可能。
- 升级后需在 Chrome/Edge 扩展管理页重新加载 0.5.9。

## 0.5.8 轻量蓝紫工作台视觉改版

- 扩展弹窗调整为浅色、柔和蓝紫点缀与半透明卡片布局，重点突出“启动当前页采集”和自动启动状态。
- OZON 商品页采集面板使用统一的蓝紫标题栏、轻量表单卡片、明确的发送按钮和低干扰状态提示。
- 最近采集日志默认展示最近 3 条，减少面板高度；完整采集记录仍保存在浏览器本地。
- 本次只调整视觉与信息层级，采集、编辑、发送、拖动、折叠、去重提醒和本轮自动启动逻辑保持不变。
- 升级后需在 Chrome/Edge 扩展管理页重新加载 0.5.8。

## 0.5.7 运费规则统一与连接加固

- 扩展运费规则已与网页 2026-07-06 最新规则同步。
- 超级轻小件增加单边不超过 60cm；高客单大件最大实重改为 25kg；移除旧的 150×80×80 额外箱规。
- 核价页加载等待增加超时和关闭处理，避免监听器残留。
- 核价页地址更新为 `v=20260710`，减少旧缓存影响。
- 升级后需要在 Chrome/Edge 扩展管理页重新加载扩展。

## 0.5.6 本轮自动启动加速

- 新商品页加载完成后约 1 秒出现采集面板。
- 如果页面刚加载不稳定导致注入失败，会自动补试一次。
- 其他使用方式和 `0.5.5` 一致。

## 0.5.5 本轮自动启动

- 毛子 ERP 已正常登录并稳定后，点击插件图标里的“开启本轮自动启动”。
- 开启后，新打开或刷新的 OZON 商品页会自动出现采集面板。
- 这个开关只在当前浏览器会话有效，关闭浏览器后默认关闭。
- 需要停止时，点击插件图标里的“关闭本轮自动启动”。
- “启动当前页采集”仍可用于只启动当前页面。

## 0.5.4 手动启动采集面板

- 为减少对毛子 ERP 登录的影响，插件默认不再自动进入 OZON 页面。
- 使用时先打开 OZON 商品详情页，确认毛子 ERP 已正常登录并加载。
- 点击浏览器右上角 `OZON ERP Detail Sender` 图标。
- 点击“启动当前页采集”，页面左侧会出现采集面板。
- 本次只需要重新加载 Chrome/Edge 扩展，不需要重新上传核价页。

## 0.5.3 核价页连接修复

- 修复“核价页已打开，但扩展没有连接上”的发送失败问题。
- 如果核价页已经打开但没有扩展接收脚本，扩展会主动补注入后再发送。
- 本次只需要重新加载 Chrome/Edge 扩展，不需要重新上传核价页。

## 0.5.2 千元以上价格识别

- 已支持 `1 234 ₽`、`1 234,56 ₽`、`1 234 ₽` 这类带千分位空格的价格。
- 四位数及以上绿标价格不会再被识别成空格前面的 `1` 或 `12`。
- 升级后请在 Chrome/Edge 扩展管理页重新加载扩展。

## 0.5.1 黑标价格

- “绿标价格”下方新增“黑标价格”。
- 每次点击“检查本页数据”后，黑标价格默认保持空白，需要人工填写。
- 点击“发送到核价页”后，黑标价格会写入 OZON 本地核价表新行的“黑标价格”列。
- 黑标价格不参与扩展端的佣金和国际运费计算。

## 0.5.0 推荐使用流程

1. 打开 OZON 商品详情页，等待毛子 ERP 数据显示完整。
2. 点击“检查本页数据”。
3. 在确认区检查 SKU、绿标价格、长宽高和重量，并手动填写黑标价格；识别错误时可以直接修改。
4. 确认自动重算的佣金、国际运费和运费渠道。
5. 点击“发送到核价页”。
6. 如果相同 SKU 或链接以前发送过，扩展会提醒，可选择取消或仍然新增一行。

## 面板功能

- 标题栏可以拖动，松开后自动记住位置。
- 点击标题栏右侧 `−` 可以折叠，点击 `+` 重新展开。
- 点击标题栏右侧恢复图标，可以把面板恢复到默认位置。
- 面板顶部显示当前版本号。
- 最近 50 条检查和发送记录保存在浏览器本地，面板显示最近 8 条，可点击“清空”。
- 修改绿标价格、尺寸或重量后，佣金和国际运费会自动重新计算。

## 移动采集面板

- 按住面板顶部的“OZON详情采集”标题栏拖动，即可把面板移动到窗口中的任意位置。
- 松开鼠标后会自动记住位置，刷新页面或重新打开商品页后仍会使用上次的位置。
- 浏览器窗口缩小时，面板会自动调整到可见范围内。

## Chrome 安装或升级

1. 打开 `chrome://extensions/`。
2. 打开“开发者模式”。
3. 已安装旧版时，点击扩展卡片上的刷新图标。
4. 新安装时，点击“加载已解压的扩展程序”，选择 `C:\Users\Microsoft\Documents\Ozon\ozon-erp-collector-extension`。

## Edge 安装或升级

1. 打开 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 已安装旧版时，点击扩展卡片上的重新加载按钮。
4. 新安装时，点击“加载解压缩的扩展”，选择 `C:\Users\Microsoft\Documents\Ozon\ozon-erp-collector-extension`。

发送给其他电脑时，使用 `C:\Users\Microsoft\Documents\Ozon\ozon-erp-collector-extension.zip`，对方必须先解压再加载文件夹。

## 现在的正确逻辑

这个扩展不再采集搜索页，也不再判断“符合要求”标签。

正确流程是：

1. 你已经提前收集好符合要求的产品详情页链接。
2. 把这些链接填入飞书“核价明细”表的“跟卖链接”列。
3. 扩展从飞书读取这些链接。
4. 扩展逐个打开 OZON 产品详情页。
5. 读取详情页右侧毛子 ERP 标签上的数据。
6. 回填同一行。

## 飞书表格需要的字段

必须有：

```text
跟卖链接
绿标价格
SKU
佣金
国际运费
```

建议额外新增，方便排查：

```text
采集状态
采集时间
采集备注
长cm
宽cm
高cm
重量kg
跟卖最低价
rFBS佣金
采集原文
```

如果额外字段没建，系统会只写入核心字段。

## 采集规则

绿标价格：

```text
毛子 ERP 标签里的“跟卖最低价”
```

SKU：

```text
毛子 ERP 标签里的 SKU
```

佣金：

```text
读取毛子 ERP 标签里 rFBS佣金 的三个档位
绿标价格 < 135：取第一档
135 <= 绿标价格 <= 600：取第二档
绿标价格 > 600：取第三档
```

国际运费：

```text
读取毛子 ERP 标签里的长宽高和重量
按 OZON 本地核价表里的国际运费规则计算
填入最低可用运费
```

## 使用

1. 更新并部署新的 Cloudflare Worker：

```text
C:\Users\Microsoft\Documents\Ozon\ozon-erp-collector-worker\worker.js
```

2. Chrome 打开：

```text
chrome://extensions/
```

3. 找到“OZON ERP 详情页采集助手”，点刷新图标。

4. 点扩展图标，填写：

```text
提交人
同步备注
同步接口地址
```

5. 点：

```text
开始读取飞书跟卖链接
```

扩展会自动逐个打开详情页。请不要关闭 Chrome。
