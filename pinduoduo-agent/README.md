# 拼多多自动找同款与采购价补全

本模块是Ozon找品任务与MuMu安卓模拟器之间的本地桥接层。它不使用拼多多官方API，而是控制用户已登录的拼多多App。

## 当前阶段（MVP 2）

- 导入已完成Ozon主图与核价的JSON。
- 只允许`pending_pinduoduo_search`任务进入模拟器阶段。
- 检查MuMu设备、安卓启动状态和拼多多安装状态。
- 将受信任的Ozon主图下载到本地运行目录，再下发到MuMu相册。
- 自动启动拼多多、按页面语义定位“拍照搜索”，在摄像头报错前快速选择最新主图。
- 自动读取当前屏以图搜结果中的候选标题和展示价，并预填最低展示价。
- 自动依次打开当前屏前3个候选详情，读取详情标题、详情展示价、商品ID、稳定链接、主图地址、优惠/限量标签和明确包邮信息，再返回搜索结果处理下一款。
- 人工确认商品规格、优惠资格及含运实付价后，自动与18%最高采购成本比较并回写JSON。
- 所有任务、图片和候选结果只保存在本机，不提交GitHub。

当前不会把搜索页或详情页最低展示价直接认定为采购成本。下一步是读取候选SKU规格选择层，核实默认规格、数量、优惠门槛和额外运费；随后接入云端AI同款判断。

## 已完成真实验证

- 2026-08-28使用任务SKU `4275207601`及其Ozon主图完成端到端测试。
- 拼多多返回3个与Milwaukee美沃奇内六角扳手套装一致的可见候选，展示价为`70.00 / 70.20 / 71.00`元。
- 该任务18%最高采购成本为`66.19`元，因此仅按当前展示价判断暂不达标；因尚未核实规格与优惠，未自动写成最终采购成本。
- 2026-08-28升级复测读取到当前屏4个候选，并连续核验前3个详情页3/3成功；详情价为`71 / 70 / 70.2`元，三个候选均取得商品链接和明确“全场包邮”字段。

## 启动

双击项目根目录的`启动拼多多找品Agent.cmd`。工具会打开：

```text
http://127.0.0.1:17628/
```

若MuMu未启动，先点击“启动模拟器”，等安卓桌面出现后点击“检查模拟器”。导入JSON后，逐件点击“自动以图找同款”；候选价出现后确认详情，再点击“写入采购价”。

## 采购价定义

拼多多采购价按商品实际支付销售价记录。拼多多商品通常含运费；如果页面另有运费，必须把运费加到商品价后再写入采购成本。
